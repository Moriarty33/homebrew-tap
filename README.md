# Moriarty33 Homebrew tap

```sh
brew install moriarty33/tap/jb-kaizen && jb-kaizen
```

[JB Kaizen](https://github.com/Moriarty33/jb-kaizen) is a Claude Code setup that improves itself every night, with the [Hoply](https://hoply.work) day review. `jb-kaizen` asks at most two questions: install the recommended set, and connect Hoply (sign in through the browser).
